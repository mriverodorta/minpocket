# Component checks

Run `make check` on Linux with a C compiler and Python 3. These checks require
no device, personal library, downloaded artwork, network connection or secrets.
They cover layout, scene order, clipping, portrait strides, font glyphs,
animation, indicator registration, navigation, caption transitions and cache
corruption recovery. Test artwork and records are synthetic.

These checks do not qualify a flashable image, emulator or save workflow.
